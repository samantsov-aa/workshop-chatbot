# Для вчителя

Заняття триває 2 години, учні працюють поодинці або в парах за комп'ютером. Найбільше часу з'їдає встановлення, тож готуйте комп'ютери напередодні. Слайди: `slides/Презентація.pdf` (або `.pptx`). Код: папка `ai-agent-starter`.

## Підготовка

- [ ] Створіть ключ у [Google AI Studio](https://aistudio.google.com/apikey) на свій обліковий запис. Умови Gemini API дозволяють користуватися ним лише з 18 років, тому учням ключ не роздавайте.
- [ ] На кожному комп'ютері скопіюйте `.env.example` як `.env` і впишіть ключ.
- [ ] Створіть `.venv`, встановіть залежності і запустіть `check_setup.py`.
- [ ] Пройдіть усі кроки на одному комп'ютері.
- [ ] Перевірте ліміти: на безкоштовному рівні діють обмеження запитів за хвилину. Для 15+ комп'ютерів увімкніть оплату або садіть учнів у пари.
- [ ] Роздрукуйте «Робочий аркуш учня» на кожного учня.
- [ ] Після уроку запустіть `python cleanup.py` на кожному комп'ютері і за потреби відкличте ключ.

## Сценарій за часом

| Хвилини | Слайди | Що відбувається |
| --- | --- | --- |
| 0–7 | 1–6 | Вступ: що таке агент, як модель вгадує слова, токени, галюцинації |
| 7–10 | 7 | Крок 0: запуск `check_setup.py` |
| 10–30 | 8–9 | Крок 1: перший чат, експерименти з інструкцією і temperature |
| 30–40 | 10–11 | Крок 2: файл у промпті |
| 40–75 | 12–14 | Крок 3: RAG, завантаження файлів, три тести, свій файл |
| 75–105 | 15–18 | Крок 4: промпт (10 хв), гра «Зламай бота» (15 хв), етика (5 хв) |
| 105–120 | 19–20 | Демо, голосування, рефлексія |

## Що чекати від учнів

Усі кроки перевірено наживо на прикладах із `materials`. Ось що повертає агент:

| Завдання | Що повинно статися |
| --- | --- |
| 1.1, локальне питання | Бот вигадує час або каже, що не знає. Правильна відповідь — до 14:00. |
| 1.1, пам'ять | Бот пам'ятає ім'я, бо чат зберігає історію розмови. |
| Крок 2 | Про бібліотеку — «до 14:00», про гурток — «немає інформації». Токенів ≈550 на перше питання, далі більше: історія розмови теж їде в кожен запит. |
| Крок 2, «Подумай» | Дорого (весь текст з кожним питанням), повільно, текст може не влізти, модель губиться в довгому тексті. |
| 3.2 | Відповіді з «Джерела: robotics\_club» чи «school\_library». На питання поза документами — «не знаю» і попередження без джерел. |
| Гра | У тесті агент не назвав секретне слово «вчителю». Інші атаки, особливо зміна мови чи анекдот, часто спрацьовують — це нормально для обговорення. |

## Якщо щось пішло не так

- **`429` у багатьох учнів одночасно** — вичерпано ліміт ключа. Попросіть пари питати по черзі або зачекати хвилину.
- **На Windows немає команди `python`** — користуйтеся `py`. Шаблон працює на Python 3.10–3.14.
- **Учень зіпсував файл** — скопіюйте його заново з чистої копії `ai-agent-starter`. `.env` і `store_name.txt` лишаються на місці.
- **Немає інтернету** — заняття без нього неможливе: усе виконується на серверах Google. Покажіть слайди і готові відповіді з таблиці вище.
