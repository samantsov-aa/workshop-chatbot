Робимо свого ШІ-помічника · Робочий аркуш, крок 3

Покажіть, що різниця між звичайним чатом і агентом з RAG — фактично один параметр tools. Решту роботи (розрізання, пошук, вибір шматків) виконує сервіс File Search від Google. Поки йде завантаження (1–2 хв), запитайте, які файли учні хочуть дати своєму агенту. Назви файлів можуть бути кирилицею: скрипт це враховує.
