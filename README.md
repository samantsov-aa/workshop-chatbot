# Заняття «Робимо свого ШІ-помічника»

Усі матеріали двогодинного заняття для школярів: як зробити агента, що відповідає за документами (RAG на Gemini File Search).

| Що | Де |
|----|----|
| Стартовий проєкт для учнів (код, приклади матеріалів) | `ai-agent-starter/` |
| Робочий аркуш учня (для друку) | `worksheets/Робочий аркуш учня.pdf` · `.md` |
| Робочий аркуш вчителя: підготовка, сценарій, очікувані відповіді | `worksheets/Робочий аркуш вчителя.pdf` · `.md` |
| Презентація, 20 слайдів | `slides/Презентація.pdf` · `slides/Презентація.pptx` (нотатки доповідача всередині) |
| Вихідні HTML слайдів і скрипт збірки | `slides/source/` |

PPTX складається зі слайдів-картинок, тому текст у PowerPoint не редагується. Щоб змінити слайд, правте `slides/source/slides/<id>.html` і перезберіть:

```bash
pip install markdown python-pptx pypdfium2 pillow
python slides/source/build.py slides/source .
```

Скрипт також перезбирає PDF робочих аркушів із `worksheets/*.md`. Потрібен Google Chrome або Microsoft Edge.
