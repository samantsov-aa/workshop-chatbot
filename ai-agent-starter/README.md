# Робимо свого ШІ-помічника 🤖

Стартовий проєкт до заняття. За 2 години ти зробиш агента, який відповідає на питання
за твоїми документами і показує, звідки взяв відповідь.

## Що де лежить

| Файл | Для чого |
|------|----------|
| `check_setup.py` | Крок 0: перевіряє, що все встановлено і ключ працює |
| `step1_chat.py` | Крок 1: перша розмова з моделлю |
| `step2_context.py` | Крок 2: даємо знання, вставивши файл у промпт |
| `step3_upload.py` | Крок 3: завантажуємо `materials/` у сховище |
| `step4_rag_chat.py` | Крок 3–4: агент із пошуком по документах (RAG) |
| `bonus_web.py` | Бонус: той самий агент у браузері |
| `cleanup.py` | Після заняття: видаляє сховище з хмари |
| `materials/` | Документи агента. Додавай сюди свої `.md`, `.txt`, `.pdf` |
| `common.py` | Спільні налаштування, міняти не треба |

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
# source .venv/bin/activate       # macOS / Linux
pip install -r requirements.txt
python check_setup.py
```

Якщо команда `python` не знаходиться, спробуй `py`.

Далі по черзі: `python step1_chat.py`, `python step2_context.py`,
`python step3_upload.py`, `python step4_rag_chat.py`. Щоб вийти з чату, напиши `вихід`.

Бонус: `streamlit run bonus_web.py`.

## Для вчителя: підготовка до заняття

1. **Ключ.** Створіть ключ у [Google AI Studio](https://aistudio.google.com/apikey) на
   свій обліковий запис (умови Gemini API вимагають, щоб користувачеві було 18+).
   Покладіть `.env` із ключем у папку на кожному комп'ютері заздалегідь, учням ключ
   не роздавайте.
2. **Встановлення.** Створіть `.venv` і встановіть залежності на всіх комп'ютерах до
   уроку: це найдовший крок, і він часто ламається через мережу.
3. **Ліміти.** На безкоштовному рівні діють ліміти запитів за хвилину. Для класу з
   15+ комп'ютерів увімкніть оплату в AI Studio або працюйте в парах.
4. **Перевірка.** Напередодні пройдіть усі кроки на одному комп'ютері.
5. **Після уроку.** Запустіть `python cleanup.py` на кожному комп'ютері, щоб видалити
   сховища, і за потреби відкличте ключ в AI Studio.
